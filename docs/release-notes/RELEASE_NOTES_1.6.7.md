# Release 1.6.7 — کیفیت و دقت مشاوره عمومی

## تغییرات
- ادعاهای قطعی درباره تقاضای بازار کار، درآمد، امنیت شغلی و درآمد دلاری بدون منبع معتبر و تاریخ‌دار ممنوع شد.
- در نبود داده به‌روز، مسیرهای شغلی به‌صورت کیفی و همراه با عوامل مؤثر بر فرصت‌ها بیان می‌شوند.
- توضیح ریاضی متوازن‌تر شد: منطق/ریاضی گسسته برای الگوریتم‌ها و آمار/احتمال/جبر خطی برای برخی مسیرهای داده و هوش مصنوعی.
- بدون چارت رسمی، مدل نباید شماره ترم یا فهرست قطعی دروس دانشگاه را ادعا کند.
- پاسخ عمومی معمولاً ۱۸۰ تا ۲۸۰ واژه و پاسخ صریحاً مفصل حداکثر ۳۵۰ واژه؛ حداکثر چهار تیتر و پررنگ‌سازی محدود به عنوان‌ها.
- تست رگرسیون مستقل برای سیاست کیفیت پاسخ اضافه شد.

## سازگاری
- هیچ فایل رابط کاربری، CSS، JavaScript فرانت‌اند یا تصویر تغییر نکرده است.
- مسیرهای API و قرارداد خروجی تغییر نکرده‌اند.

## اعتبارسنجی
- تست‌های Provider شبیه‌سازی‌شده و سیاست کیفیت باید اجرا شوند.
- کیفیت پاسخ با Provider واقعی پس از Deploy باید دوباره ارزیابی شود؛ این نسخه ادعای داشتن منبع زنده بازار کار ندارد.
