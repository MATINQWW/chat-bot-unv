# Release 1.6.6 — درخواست کم‌حجم برای سؤال عمومی و پاسخ کامل‌تر

## اصلاح ریشه‌ای 413
- سؤال‌های عمومی از ابتدا بدون بازیابی دانش دانشگاه و بدون Prompt چند هزار نویسه‌ای ارسال می‌شوند.
- Prompt عمومی به چند دستور کوتاه و مرتبط محدود شده است.
- بودجه پاسخ عمومی به‌ترتیب 700، 520 و 400 توکن است؛ در Retry هم سؤال و Prompt کوچک‌تر می‌شوند.
- برای سؤال‌های رسمی/ترکیبی، Prompt پایه کوتاه شده و فقط منبع مرتبط دانشگاه فرستاده می‌شود.
- اندازه درخواست و بودجه خروجی به‌شکل امن و بدون ثبت متن پیام در Runtime Logs ثبت می‌شود.

## ادامه پاسخ
- قطعه‌های ادامه به 320 و 200 توکن افزایش یافته‌اند تا پاسخ‌های بلندتری تکمیل شوند.
- اگر ادامه ناموفق باشد، پاسخ به‌اشتباه کامل علامت‌گذاری یا وارد حافظه یادگیری نمی‌شود.

## محدودیت اعتبارسنجی
تست‌ها با Provider سازگارِ شبیه‌سازی‌شده اجرا می‌شوند. پذیرش نهایی و سقف Context سرویس واقعی IranCopilot باید با Runtime Logs نسخه منتشرشده تأیید شود. هیچ فایل ظاهری یا CSS/JS فرانت‌اند در این نسخه تغییر داده نشده است.
