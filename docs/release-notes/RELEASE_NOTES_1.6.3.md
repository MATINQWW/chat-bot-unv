# Release 1.6.3 — پاسخ کامل در مسیر بازیابی خطای 413

## اصلاح اصلی

- سقف پاسخ در آخرین تلاش فشرده از ۱۲۸ به ۴۰۰ توکن افزایش یافت؛ سقف ۱۲۸ باعث قطع پاسخ‌های فارسی در میانه جمله می‌شد.
- در آخرین تلاش، تاریخچه و دانش بازیابی‌شده همچنان حذف می‌شوند تا فضای بیشتری برای پاسخ باقی بماند.
- متن سؤال در مسیر فشرده تا ۳۲۰ نویسه حفظ می‌شود.
- تست بازیابی 413 اکنون بررسی می‌کند که درخواست فشرده با سقف ۴۰۰ توکن پذیرفته شود.

## دامنه تغییر

فقط API چت، تست مربوط به fallback، نسخه بسته و مستندات تغییر کرده‌اند. فایل‌های HTML/CSS/JS سمت کاربر و دارایی‌های ظاهری دست‌نخورده‌اند.

## نکته انتشار

این اصلاح در محیط تست محلی/شبیه‌سازی‌شده قابل بررسی است. پذیرش درخواست توسط سرویس واقعی IranCopilot و کامل بودن پاسخ پس از Deploy باید با تست واقعی تأیید شود.
